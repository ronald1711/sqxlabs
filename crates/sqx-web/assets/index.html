Overview

Getting started

  1. Builder — edit the strategy, backtest it, export to MQL5 / NinjaScript / EasyLanguage.
  2. Optimizer — generate candidates, or run walk-forward / walk-forward matrix with parameter ranges.
  3. Retester — what-if cost scenarios and Monte Carlo trade manipulation.
  4. Results — persistent databank, filter, combine top strategies into a portfolio, download CSV.
  5. Data Manager — import CSV, broker profiles, sessions.
  6. Projects — build → retest → optimize pipeline.
  7. AI assistant — ask the engine in natural language.
